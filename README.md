# 汉东人格档案

一个移动端优先的中文娱乐答题网站：16 道题，测测你最像《人民的名义》中的谁。

## 功能

- 首页说明与非官方娱乐测试免责声明
- 16 道单选题
- 进度条
- 返回上一题
- 非随机计分结果
- 结果页展示角色、人格标签、总结、优势、风险点、组织生存建议、适配搭档、危险搭档、分享文案
- 角色档案库跳转
- 复制分享文案
- 重新测试

## 本地运行

```bash
npm install
npm run dev
```

打开本地地址：

```txt
http://127.0.0.1:5173
```

## 构建

```bash
npm run build
```

构建产物会生成在 `dist/` 目录，可部署到 Vercel、Netlify 或任意静态网站托管服务。

## 内容与合规说明

本项目为非官方影视娱乐人格测试，仅用于娱乐和自我观察；不涉及现实人物、现实机构或政治评价，也不构成心理诊断。

页面不使用官方剧照、演员照片、官方 logo 或长台词引用。
